Rework the solar-wind flow tracking interface: ``punchbowl.level3.velocity.track_velocity`` now requires a ``product_code`` argument, derives its reference time from the input files' metadata, replaces ``ycens`` and ``rbands`` with ``annuli_centers_rs`` and ``annuli_width_rs``, and adds parameters controlling the tracking window and preprocessing (``frames_per_window``, ``delta_px``, ``expected_wind_kps``, ``offset_speed_kps``, ``vel_bin_width``, ``speed_max``, ``buffer_target_hours``, ``use_median``, ``rotate90``, ``remove_temporal_median``, ``deflicker``, ``hdu``). Generating a level-3 VAM now requires enough input files to cover the tracking window plus a ``buffer_target_hours`` temporal-average buffer (about 183 PTM frames with default settings), and punchpipe configurations should rename the ``ycens`` key to ``annuli_centers_rs``.
